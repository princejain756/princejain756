I'm a software developer based in India. I run Quantiti, ship client sites, and keep a rotating cast of open-source tools and side projects going. Mostly TypeScript; Kotlin, Swift, Python and C# when the job calls for it.

## Things I've shipped

- [MaintainerOS](https://github.com/princejain756/MaintainerOS) - a command center for open-source maintainers: repo health, stale backlog, security readiness, issue triage, PR review and GitHub Actions reports. Live at [maintaineros.prince.sh](https://maintaineros.prince.sh).
- [Higgsfield-Open](https://github.com/princejain756/Higgsfield-Open) - open-source AI creative studio for the Higgsfield API: Seedance 2.5 with face-lock character continuity, 38 frontier models, per-generation pricing, no markup.
- [SnapStudio](https://github.com/princejain756/SnapStudio) - privacy-first image editor that runs entirely in the browser. Screenshots, thumbnails, annotations, filters, exports.
- [readmeroast](https://github.com/princejain756/readmeroast) - roasts unclear READMEs and helps rewrite them into something people actually want to read.
- [Hermdroid](https://github.com/princejain756/Hermdroid---Hermes-App-For-Android) - native Android control surface for a self-hosted Hermes agent. The agent and its files stay on your server; the app owns the interaction.
- [Zero-Power-Player](https://github.com/princejain756/Zero-Power-Player) - ultra-low-power local MP3 player, ambient mixer and Pomodoro deck for long study sessions.
