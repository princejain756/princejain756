I'm a software developer based in India. I run Quantiti, ship client sites, and keep a rotating cast of open-source tools and side projects going. Mostly TypeScript; Kotlin, Swift, Python and C# when the job calls for it.

## Things I've shipped

- [ctxvitals](https://github.com/princejain756/ctxvitals) - a Lighthouse for your AI agent stack: measures the real token cost of MCP servers, skills and rules; flags security issues and duplicates; grades the setup A-F.
- [slopsieve](https://github.com/princejain756/slopsieve) - score a diff or PR for AI-slop review signals: test weakening, debug leftovers, trivial deps, dead exports. A linter for unreviewed generation.
- [dep-census](https://github.com/princejain756/dep-census) - count the strangers inside node_modules: who actually maintains the code your app runs.
- [mcp-tax](https://github.com/princejain756/mcp-tax) - see how many tokens your MCP servers burn before you type a word.
- [agent-trials](https://github.com/princejain756/agent-trials) - interview your coding agent before you ship with it: same task suite through every agent CLI, sandboxed, scored.
- [readmeroast](https://github.com/princejain756/readmeroast) - score any GitHub README out of 100 and get roasted for what it's missing.
- [MaintainerOS](https://github.com/princejain756/MaintainerOS) - a command center for open-source maintainers: repo health, stale backlog, security readiness, issue triage, PR review and GitHub Actions reports. Live at [maintaineros.prince.sh](https://maintaineros.prince.sh).

Lately: tracing a Long-to-int narrowing bug class through [kestra](https://github.com/kestra-io/kestra) and its upstream templating engine, [pebble](https://github.com/PebbleTemplates/pebble).
